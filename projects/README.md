# ที่เก็บโปรเจกต์วิดีโอ

ให้ใช้ External SSD เป็นที่เก็บหลัก โดยสร้าง `Video_Projects/` ที่ root ของไดรฟ์ แล้วสร้างโฟลเดอร์หนึ่งชุดต่อหนึ่งงานด้วยการคัดลอก `_TEMPLATE` และเปลี่ยนชื่อเป็นชื่อโปรเจกต์ เช่น `2026-10-09-trip-vlog` จากนั้นเก็บไฟล์ของงานไว้ภายในโฟลเดอร์นั้นทั้งหมด

> ตรวจพื้นที่ว่างบน SSD ก่อนคัดลอกการ์ดหรือไฟล์วิดีโอทุกครั้ง เพราะฟุตเทจความละเอียดสูงและไฟล์ 360° ใช้พื้นที่มาก

## นำไฟล์จากกล้องลงที่ไหน

โอน/คัดลอกไฟล์จากกล้องหรือการ์ดลงโฟลเดอร์โปรเจกต์บน External SSD ก่อน แล้วให้ CapCut Import จากตำแหน่งนั้นโดยตรง ไม่ต้องทำสำเนาฟุตเทจชุดใหญ่ลง internal drive

- **Osmo 360:** คัดลอกไฟล์ 360° ต้นฉบับไปที่ `01_FOOTAGE/00_CAMERA_ORIGINALS/OSMO_360/` แล้วรีเฟรมใน DJI Studio ส่งออกเป็น MP4 ไปที่ `01_FOOTAGE/01_PREPARED/OSMO_360_REFRAMED/` ก่อนนำ MP4 ไปตัดใน CapCut
- **DJI Action 6:** คัดลอกต้นฉบับไปที่ `01_FOOTAGE/00_CAMERA_ORIGINALS/ACTION_6/` ถ่าย 1:1, 16:9 หรือ 9:16 ก็เก็บต้นฉบับไว้ตรงนี้ แล้วนำเข้า CapCut ได้เลย ไม่ต้องสร้างไฟล์แปลงใหม่เพียงเพื่อเปลี่ยนอัตราส่วน
- **iPhone:** คัดลอกไฟล์ต้นฉบับไปที่ `01_FOOTAGE/00_CAMERA_ORIGINALS/IPHONE/`
- **เสียงแยก:** เก็บเสียงต้นฉบับใน `02_AUDIO/ORIGINALS/` และไฟล์เสียงที่ผ่านการปรับ/ประมวลผลแล้วใน `02_AUDIO/PROCESSED/`

## โฟลเดอร์อื่น

- `03_PROJECT_FILES/CAPCUT/` — ไฟล์โปรเจกต์ CapCut และไฟล์ประกอบที่ต้องใช้เปิดโปรเจกต์
- `04_EXPORTS/YOUTUBE/` และ `04_EXPORTS/TIKTOK/` — วิดีโอส่งออก แยกตามแพลตฟอร์ม
- `05_THUMBNAILS/YOUTUBE/` และ `05_THUMBNAILS/TIKTOK/` — ภาพปกแยกตามแพลตฟอร์ม
- `06_NOTES/` — shot log, timecode, ลำดับเรื่อง และบันทึกการตัดสินใจ

## ตัดต่อจาก External SSD ด้วย CapCut

- Import ไฟล์ต้นฉบับและไฟล์ที่เตรียมแล้วจากโฟลเดอร์โปรเจกต์บน SSD โดยตรง แล้วตัดต่อจาก SSD ได้เลย
- หาก CapCut รุ่นที่ใช้อยู่ให้เลือกตำแหน่งเก็บ draft/project ได้ ให้เลือก `03_PROJECT_FILES/CAPCUT/` บน SSD หากแอปจัดเก็บ draft ไว้ในโฟลเดอร์ของแอปเอง ให้ปล่อยไว้ตามนั้นและเก็บไฟล์สำรอง/ไฟล์ประกอบของงานไว้ในโฟลเดอร์นี้
- ระหว่างตัดต่อและ export ให้เสียบ SSD ค้างไว้ อย่าถอด เปลี่ยนชื่อไดรฟ์ ย้ายโฟลเดอร์ หรือย้ายไฟล์ที่ CapCut ใช้อยู่ มิฉะนั้นอาจขึ้น Media Not Found
- หลังสร้างโปรเจกต์ครั้งแรก ให้บันทึก ปิดแล้วเปิดทดสอบอีกครั้งเพื่อเช็กว่า CapCut ยังหา media บน SSD เจอ
- ถ้าเผลอถอด SSD ระหว่างเปิด CapCut ให้เสียบกลับ แล้วกด "Click to refresh the media list" ที่แถบแจ้งเตือน และเช็กว่าไม่มีคลิปขึ้น Media Not Found ครั้งหน้าให้ปิด CapCut และ Eject ใน Finder ก่อนถอด
- **CapCut เล่นแล้วไม่มีเสียง** หลังเสียบ/ถอดอุปกรณ์ USB (ไมค์, SSD) ทั้งที่ Volume ของคลิปปกติ: ปิด CapCut (CapCut → Quit) แล้วเปิดโปรเจกต์ใหม่ เสียงจะกลับมา
- **อัดเสียงพากย์ใน CapCut Desktop:** ต่อไมค์ (เช่น DJI MIC MINI ผ่าน USB) → เลื่อนหัวอ่านไปจุดเริ่ม → กดไอคอนไมค์เหนือ timeline → เลือก Input device ทุกครั้งหลังเปิดแอปใหม่ (ค่าจะกลับเป็นไมค์ MacBook) → ใส่หูฟังหรือเปิด Echo reduction หน้าต่าง Voiceover อาจเปิดล้นขอบจอ ต้องลากเข้ามาก่อนจึงเห็นปุ่มอัด
- **ย้ายไปตัดต่อในมือถือ:** ที่หน้า Home คลิกขวาโปรเจกต์ → Upload → เลือก Space ของบัญชี มือถือต้องใช้ CapCut 8.1.0 ขึ้นไปและล็อกอินบัญชีเดียวกัน การแก้ในมือถือไม่ซิงก์กลับอัตโนมัติ ต้องอัปโหลดกลับจากมือถือเอง
- เก็บไฟล์ส่งออกและ Thumbnail กลับไปยังโฟลเดอร์ `04_EXPORTS/` และ `05_THUMBNAILS/` ของโปรเจกต์เดียวกัน

## หลักการเก็บไฟล์

- คัดลอกไฟล์จากการ์ด/กล้องเข้าที่ `00_CAMERA_ORIGINALS` ก่อนเริ่มงาน อย่าตัดต่อหรือเขียนทับไฟล์ต้นฉบับ
- สำรองต้นฉบับไว้จนกว่างานและไฟล์ส่งออกจะตรวจเรียบร้อย
- ไม่จำเป็นต้องทำไฟล์ `PREPARED` ซ้ำทุกกล้อง ให้สร้างเฉพาะเมื่อมีขั้นตอนเตรียมจริง เช่น Osmo 360 ที่ต้องรีเฟรม หรือไฟล์ที่ต้องแปลงเพื่อแก้ปัญหาความเข้ากันได้
- Action 6 ที่ถ่าย D-Log M สามารถเก็บต้นฉบับไว้ แล้วทำ color normalization ด้วย DJI D-Log M to Rec.709 LUT ใน CapCut Desktop สำหรับงาน SDR/Rec.709 โดยไม่ต้องสร้างไฟล์แปลงทับต้นฉบับ
- ตั้งชื่อโปรเจกต์ด้วยวันที่และหัวข้อสั้น ๆ เช่น `YYYY-MM-DD_topic` เพื่อค้นหาและแยกงานได้ง่าย
- ตรวจพื้นที่ว่างก่อนโอน footage และก่อน export ทุกครั้ง; พื้นที่ว่างเปลี่ยนได้ตามไฟล์ที่เก็บและขนาดของโปรเจกต์
